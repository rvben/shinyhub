# ShinyHub logo exploration — iteration V2

The selected first-round **Orbit Hub** logo remains unchanged under
`assets/branding/selected/`. This directory contains ten additional directions
that preserve its central spark and Constellation palette while exploring new
structures.

| # | Direction | Structural idea |
|---|-----------|-----------------|
| 01 | Eclipse Gate | Broken ring with a deliberate upper-right gateway |
| 02 | Relay Ring | Three relay segments handing off around the hub |
| 03 | Constellation Seal | Rounded hexagonal infrastructure badge |
| 04 | Four Corners | Four app brackets focused on one central spark |
| 05 | Spark Portal | Opposing portal brackets with two endpoints |
| 06 | Orbit Stack | Layered dashboard arcs converging at the hub |
| 07 | Signal Loop | One continuous lifecycle loop |
| 08 | Compass Hub | Four directional arcs for orientation |
| 09 | Linked Halo | Three modular capsules in a collaborative halo |
| 10 | Zenith Orbit | Crescent and rising nodes suggesting healthy wake |

Every PNG has genuine transparency and an adjacent prompt file embedded into
its metadata for provenance. These are raster direction studies; the chosen
final should be redrawn as deterministic vector artwork.
