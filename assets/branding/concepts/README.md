# ShinyHub logo concepts

Early raster concepts generated for brand-direction review.

- `shinyhub-orbit-hub.png` — central sparkle with a connected orbital hub.
- `shinyhub-launchpad.png` — four dashboard tiles gathered around a launch sparkle.
- `orbit-hub.prompt.txt` and `launchpad.prompt.txt` — exact generation prompts,
  also embedded in the PNG metadata for provenance.

These PNGs are suitable for visual review and marketing mockups. Before sending
a final design to print, redraw the selected direction as vector artwork and
prepare dedicated mark-only, horizontal, monochrome, and sticker-cut variants.
