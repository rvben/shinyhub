A notification, not an interruption.

  • SignalThe main Switch app control changes its secondary line to “Update ready.” No extra version button appears beside bookmarks.
  • ActionCyan remains the single decisive action: explicitly reload into the latest switchable generation.
  • PersistenceClosing the panel preserves “Update ready” on the switcher; hiding all chrome preserves a dot on the restore tab.
  • ControlNo automatic reload. The visitor decides when to switch during the configured drain window; an overlong session may be closed at its operator-set limit.

The interaction follows deployment truth

The interface appears only when the replacement generation is healthy and every currently serving control-plane node can route it.

Current version serves

The browser remains pinned to the generation that rendered the page. Nothing visual changes while a candidate builds.

Replacement becomes ready

Only an all-ready, fleet-switchable generation produces the notice. A failed candidate stays invisible.

Visitor switches

A same-origin handshake selects the latest generation, then reloads the exact path, query, and hash.

Old version retires

It stops after its tracked requests and sessions drain, or at the configured hard drain limit.

One hierarchy, even with bookmarks enabled

The update belongs to app switching, so it is expressed on the app switcher—not introduced as another peer action in the toolbar.

Implementation-ready boundaries

These constraints keep the convenience layer honest, accessible, and independent from deployment correctness.

Availability

  • Poll only while visible, with jitter and backoff.
  • Quietly tolerate network, authorization, and old-server errors.
  • No app navigation or blocked injection means no notice—not reduced continuity.

Switching

  • Never auto-reload.
  • Disable duplicate submissions while pending.
  • On failure, retain the old generation and offer an inline retry.
  • Target the latest switchable generation if another activation arrived.

Accessibility

  • Announce the availability transition once with a polite atomic live region.
  • Do not move focus when state changes.
  • Meet WCAG 2.2 AA, 44px mobile targets, 200% zoom, and reduced motion.
  • Announce only meaningful retirement thresholds.

Security and trust

  • The opaque generation token authorizes nothing.
  • Status and switching enforce normal app access and support scope.
  • The endpoint reveals no deployment metadata.
  • The injected notice is convenience chrome, never a security indicator.
